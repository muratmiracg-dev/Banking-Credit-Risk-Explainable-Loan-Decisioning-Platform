# Security policy

## Supported version

Only the latest `main` branch is maintained for this portfolio project.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability involving secrets, authentication
bypass, dependency compromise or data exposure. Use GitHub's private vulnerability reporting
feature if enabled for the repository.

Include:

- affected component and version;
- reproducible steps;
- expected and observed behavior;
- estimated impact;
- suggested mitigation, if known.

## Data warning

Never submit real applicant, customer, employee or account data. The project is designed only
for synthetic data.

## Security boundary

The committed API key option, container hardening and network policy are reference controls.
They do not constitute a complete production security architecture.
